# 옵시디언 메모 → 지식 카드
옵시디언 보관함을 스캔해 메모를 주제별로 묶고, 주제마다 한 페이지 카드를 `cards` 폴더에 만드세요. 카드 점검 요청도 처리합니다.

## 입력
- 스캔할 폴더 경로 (기본: 보관함 전체)
- 묶는 기준: 태그 기반(기본) / 자동 군집(옵션)

## 그룹핑 규칙
- 기본은 태그 기반. 자동 군집은 옵션이며, 주제명을 사용자에게 확인받음
- 메모가 하나뿐인 주제는 카드를 만들지 않음 (원본 메모를 여는 것과 다를 게 없음)
- 원본 메모는 절대 수정하지 않음. 카드만 새로 생성

## 카드 구조 (`cards/{주제}.md`)

```
---
title: "{주제}"
created: YYYY-MM-DD
source_count: {출처 메모 수}
tags: [knowledge-card, {주제}]
---

# {주제}

## 핵심 요약
- 메모들에서 공통으로 드러나는 요점 2~4개

## 상세 메모 (출처별)
### {원본 메모 파일명}
- 해당 메모의 핵심 한두 줄

## 미해결 질문
- 메모에 답이 없는 질문 (없으면 생략)

## 출처 메모 목록
- 카드에 들어간 모든 원본 메모를 위키링크로
```

## 점검 (사용자가 점검을 요청할 때)
- 카드 내용과 그 카드의 출처 메모 최신본이 어긋나면 보고하고, 어느 쪽을 남길지 물음
- 어느 카드에도 안 묶인 메모를 찾아 주제가 가까운 카드를 제안
- 점검은 보고만 함. 사용자가 확인해야 카드를 고침

## 주의사항
- 출처는 위키링크로 표기해 옵시디언 그래프에서 연결되도록 유지
- 카드를 지어내지 않음. 메모에 있는 내용만 담음
