# 메모 → 주간업무보고
지정한 기간의 데일리 노트를 읽어 제출용 주간업무보고를 만드세요.

## 입력
- `daily` 폴더의 해당 주 데일리 노트 (사용자가 기간 지정)
- 기간을 주지 않으면 이번 주로 보고 확인

## 출력
- 워드 파일 (`.docx`). 표 두 개로 구성
  - 금주 실적: 한 주 동안 끝낸 일
  - 차주 계획: 다음 주에 할 일

## 정리 규칙
- 데일리 노트에 적힌 내용만 옮김. 없는 성과를 만들지 않음
- 개인 일정(운동·독서 같은 것)은 보고서에서 제외
- 데일리 노트가 없는 날은 빈칸으로 두고, 어느 날이 비었는지 함께 알림

## 주의사항
- 같은 일이 여러 날에 걸쳐 있으면 한 줄로 합치고 기간을 표시
- 보고서 문장은 완결형으로. 메모의 단어 나열을 그대로 옮기지 않음
