# 노션 DB 정리

노션 MCP로 지정한 DB의 모든 항목을 읽고, 아래 분류 기준에 맞춰 태그(또는 속성)를 갱신하세요.

## 입력

- 노션 DB URL
- 정리 대상 속성명 (예: 상태, 카테고리, 우선순위)

## 분류 기준 (예시: 상태 속성)

- "진행중", "진행 중", "Working", "WIP" → 진행중
- "완료", "완성", "Done", "끝" → 완료
- "보류", "Hold", "Pending" → 보류
- 비어 있음 → 본문/제목에서 추론, 추론 불가능하면 "분류 필요"

## 출력 양식

### 정리 결과 ({DB명})

- 총 항목 수: N개
- 갱신 항목: N개
- 분류 필요 (수동 확인): N개

### 갱신 내역 (샘플 10건)

| 페이지 제목 | 이전 태그 | 변경 후 |
|---|---|---|

### 분류 필요 항목

| 페이지 제목 | URL |
|---|---|

## 주의사항

- 갱신 전 사용자에게 미리보기를 출력하고 확인을 받음. 자동 갱신 금지
- "분류 필요"로 판정한 항목은 절대 자동 갱신하지 않음
- 본문 추론 시 근거를 한 줄로 함께 표시
- 갱신 후 노션 페이지 last edited time이 변경되니 사용자에게 안내
