# 흩어진 자료 → 노션 DB 등록
자료에서 항목을 뽑아 대상 노션 DB에 등록하세요. 등록 전에 미리보기를 보여 주고 승인을 받습니다.

## 입력
- 대상 DB URL (사용자가 지정)
- 자료 파일 여러 개 (메모·메일 등)

## 입력 → DB 속성 매핑
- 대상 DB URL에서 속성 목록(이름·타입)을 먼저 읽는다
- 입력에서 찾은 값을 속성 타입에 맞춰 변환 (날짜→날짜, 선택→옵션, 사람→담당)
- 매칭되는 속성이 없는 정보는 페이지 본문에 메모로 남긴다
- 확실하지 않은 값은 채우지 않고 비워둔다 (추론으로 지어내지 않음)

## 중복 방지
- 등록 전 DB에서 같은 제목·같은 날짜 항목을 검색해, 있으면 건너뛴다
- 결과 표에 "신규 / 중복(건너뜀)"을 함께 표시

## 주의사항
- 미리보기를 보여 주고 사용자가 승인해야 등록함
- 출처 자료를 항목마다 표시 (메모 / 메일)
