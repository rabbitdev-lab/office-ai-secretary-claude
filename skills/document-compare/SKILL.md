# 문서 비교 분석 리포트
입력받은 문서 2~5개를 읽고 비교 리포트를 만드세요. 결과는 대화로 보여주고, 사용자가 요청하면 마크다운 파일로 저장합니다.

## 입력
- 문서 2~5개 (PDF, 마크다운, 텍스트)
- 비교 관점 (예: 가격, 일정, 제공 범위. 비어 있으면 자동 설정)

## 출력 양식
```
# 문서 비교 분석 리포트

## 한눈에 보기
| 항목 | 문서A | 문서B | ... |

## 공통점

## 차이점

## 상충하는 내용

## 추가 확인이 필요한 부분
```

## 주의사항
- 비교 관점이 비어 있으면 "전체적인 공통점·차이점"으로 자동 설정
- 한눈에 보기 표는 비교 관점 항목별로 행 구성
- 상충하는 내용이 없으면 "상충하는 내용 없음"으로 표시 (억지로 만들지 않음)
- 문서마다 단위가 다르면 (예: 원/달러) 통일하지 않고 그대로 표시한 뒤 주석으로 환산값 함께 표시
