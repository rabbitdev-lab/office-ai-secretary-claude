# 액션 아이템 follow-up
`meetings/`에서 최근 4주(또는 사용자 지정 기간) 회의록 마크다운을 모두 읽어 액션 아이템을 추출하세요. 노션 호출은 하지 않습니다 (속도·비용 이유).

## 추출 규칙
각 회의록의 “액션 아이템” 섹션에서 다음 형식으로 항목 수집:
- 회의명 / 회의 일자 / 담당자 / 할 일 / 기한 / 완료 표시(있으면 ✅)

## 분류
오늘 날짜 기준으로 다음과 같이 분류:
- **본인 / 진행 중**: 본인 담당, 기한 미도래
- **본인 / 임박**: 본인 담당, 기한 7일 이내
- **본인 / 지연**: 본인 담당, 기한 지남, 완료 표시 없음
- **타인 / 진행 중·임박·지연**: 타인 담당, 동일 기준
- **불명**: 담당자를 식별하지 못한 액션 (카운트만)
- **완료**: 완료 표시 있음 (카운트만)

## 출력 양식

### 📋 액션 점검 — 최근 N주 ({시작일} ~ {끝일})
회의록 N건 · 액션 N건 (본인 N / 타인 N / 불명 N)

#### 🔴 본인 지연 (N)
- [회의일자] 할 일 — 마감 {날짜} (N일 지남) · {회의록 파일}

#### 🟡 본인 임박 7일 이내 (N)
- [회의일자] 할 일 — 마감 {날짜} (D-N) · {회의록 파일}

#### 🔴 타인 지연 (N, 본인이 추적하는 항목)
- [회의일자] @담당자 — 할 일 (마감 {날짜}, N일 지남) · {회의록 파일}

같은 액션이 여러 회의록에 반복되거나 후속 회의록에서 완료 표시되면 ⚠️로 함께 표시.

### 후속 조치 옵션
1. 본인 임박·지연 항목을 본인 todo 도구(예: 노션 todo, Things)에 추가할지 물음
2. 타인 지연 항목 담당자에게 슬랙 DM 리마인드를 보낼지 물음
   - 사용자 동의 시에만 발송. 자동 발송 금지

## 주의사항
- 본인 식별: `data/me.md`에서 읽음 (한글 이름·슬랙 핸들 정의)
- 완료 표시 인식: 회의록 액션 아이템 줄 끝의 ✅ 또는 frontmatter `completed: [...]` 둘 다
- 기한 표기 인식: “5/2”, “2026-05-02”, “다음 주 화요일” 등 다양한 표현. 모호하면 “기한 미정”으로 분류
- 노션 페이지는 호출하지 않음. 내 컴퓨터의 마크다운 파일만 읽음
- DM 리마인드는 담당자별 1건으로 합쳐서 발송. 같은 사람에게 5건 따로 보내지 않음
