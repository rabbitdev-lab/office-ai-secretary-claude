# 슬랙 액션 아이템 분류

직전 /slack-daily-briefing 출력을 입력받아, 사용자가 오늘부터 어떻게 움직여야 할지 4분면으로 정리하세요.

## 입력
- 직전 /slack-daily-briefing 출력 (마크다운 텍스트). 채팅창 컨텍스트에 있으면 자동 사용
- 입력이 없으면 "먼저 /slack-daily-briefing을 실행해 주세요"라고 안내하고 종료

## 분류 기준

### 🔴 오늘 처리 (긴급 + 중요)
- 기한이 오늘이거나 24시간 이내
- 클라이언트·임원이 답변을 기다리는 항목
- 미루면 다른 사람의 작업을 막는 의존성 있는 항목
- 사용자가 "@나" "확인 부탁드립니다" 등으로 명시 호출된 항목

### 🟡 이번 주 처리 (중요·급하진 않음)
- 기한이 이번 주 안인 명시적 약속
- 사용자 본인 산출물이되 마감이 며칠 여유 있는 것
- 기한이 명시되지 않은 본인 담당 항목 (마감을 "이번 주 금요일"로 가정)

### 🔵 추적만 (남이 담당, 내가 결과를 받음)
- 다른 팀원이 진행 중이고 내가 결과 인수자
- "누가 / 무엇 / 언제까지 / 내가 체크할 시점" 형식으로 정리
- 회신 시점이 지나면 사용자가 리마인더를 보낼 수 있게 메모

### 🟢 정보성 (내 액션 없음)
- 단순 결정 사항·완료 보고 등 인지만 하면 되는 항목
- 결론 없이 끝난 논의

## 출력 양식

### 🔴 오늘 처리
- [ ] 할 일 (#채널, 맥락 한 줄, 예상 N분)

### 🟡 이번 주 처리
- [ ] 할 일 (#채널, 마감일, 예상 N분)

### 🔵 추적만
- 누가 / 무엇 / 언제까지 / 내가 체크할 시점

### 🟢 정보성
- 한 줄 요약

## 주의사항
- 🔴 항목은 최대 5개. 그 이상이면 🟡로 보내고 메모로 알리기
- "할게요" "하겠습니다" 같은 명시적 약속은 발화자에게 귀속해 🔵로 분류
- 채널과 원문 링크는 가능하면 함께 출력 (브리핑에 있으면 활용)
- 주말·휴일에 실행되면 🔴의 마감을 다음 영업일로 이월
