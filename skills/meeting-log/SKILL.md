# 회의 스크립트 → 회의록 저장
사용자가 지정한 `data/` 안의 회의 스크립트 파일을 읽어 구조화한 뒤 `meetings/` 폴더에 저장하세요. 경로를 주지 않으면 어떤 파일을 쓸지 먼저 묻습니다.

## 입력
- `data/` 폴더의 회의 스크립트 마크다운 파일 (사용자가 경로를 지정)
- 경로를 받지 못하면 어떤 파일을 쓸지 먼저 묻고, 임의로 고르지 않음
- 원본 스크립트 파일은 수정하거나 지우지 않음

## 구조화
- 회의명 / 일시 / 참석자
- 주요 논의 (불릿 3~5개)
- 결정 사항 (담당자 표기)
- 액션 아이템 (담당자 / 할 일 / 기한)
- 다음 회의 안건 후보

## 저장
`meetings/{YYYY-MM-DD}-{회의명}.md`로 저장.

frontmatter:

---
meeting: {회의명}
date: {YYYY-MM-DD}
attendees: [...]
series: {회의명에서 일자·차수를 뺀 제목}
---

## 주의사항
- 담당자나 기한이 빠진 액션은 “⚠️ 담당 미정” 또는 “⚠️ 기한 미정”으로 표시
- 스크립트에 시각·참석자가 없으면 사용자에게 한 번 묻고, 답이 없으면 “미상”으로 채움
- 회의록은 저장만. 노션·슬랙 공유는 하지 않음 (공유는 이 실습 끝의 “분배” 업그레이드 참고)
