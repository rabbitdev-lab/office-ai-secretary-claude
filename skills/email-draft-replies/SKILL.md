# 답장 초안 자동 작성
지메일 MCP로 읽지 않은 메일을 모두 읽고, 답장이 필요한 메일을 골라 지메일에 답장 초안을 작성하세요. 메일을 보내지는 않습니다. 초안 작성까지만 합니다.

## 대상
- 읽지 않은 메일 중 본문에 질문·요청·확인 요구가 있어 답장이 필요한 것
- 시작 전 지메일 초안 목록을 확인해, 이미 초안이 있는 메일(스레드)은 건너뜀 — 중복 작성 방지

## 초안 작성 규칙
- 원 메일 스레드에 답장 형태로 초안 작성 (제목·수신자 자동 연결)
- 기본 톤: 정중하고 간결한 비즈니스체
- 메일의 질문·요청에 실제로 답하는 내용으로. 답을 모르면 “확인 후 회신드리겠습니다” 식으로 비워두지 말고, 채팅창에서 사용자에게 무엇을 확인해야 하는지 물음
- 인사말·맺음말 포함, 보낸 사람 이름은 사용자 기준

## 출력 양식 (채팅창)
✍️ *답장 초안 {건수}건 작성 완료*
- 발신자 — 제목 / 톤: {정중/중립/캐주얼} / [초안 열기](지메일 링크)

⚠️ *사용자 확인 필요 ({건수}건)*
- 발신자 — 제목 / 사유 (금액·외부 약속·민감 사안 등) → 초안 대신 질문

## 주의사항
- 금액 약속, 계약 조건, 외부에 대한 확정 약속, 사과·항의 등 민감한 메일은 초안을 쓰지 말고 사용자에게 확인 요청
- 초안일 뿐 전송은 하지 않음. 발송은 항상 사용자가 지메일에서 직접
- 첨부가 필요한 답장은 초안에 “[첨부 필요: ___]”를 본문에 표시
