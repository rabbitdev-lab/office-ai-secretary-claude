# 주간 마무리
이번 주 주간 계획과 한 주치 일일 마무리를 읽고, 달성률과 미완료 원인을 정리해 저장하세요.

## 입력
- 이번 주 계획: `plans/{YYYY}-W{NN}-weekly.md`
- 한 주치 일일 마무리: `reviews/{YYYY-MM-DD}-daily.md`
- 지난 2주 주간 회고: `reviews/{YYYY}-W{NN}-weekly-review.md` (원인 패턴 확인용)

## 출력 양식 (`reviews/{YYYY}-W{NN}-weekly-review.md`)

```
# {YYYY}년 {NN}주차 주간 마무리

## 주간 목표 달성률

| 주간 목표 | 완료/전체 | 달성률 |
|---|---|---|

## 미완료 원인 분석
- 원인별 건수

## 다음 주 이월
- 항목 + 처리 방식 권고

## 회고
- 한 단락
```

## 주의사항
- 달성률은 주간 목표별 완료 항목 수 기준
- 미완료 원인은 하루 요약의 분류를 합산. 같은 원인이 3주 연속이면 강한 경고(구조적 문제 신호)
- 회고는 한 단락만. 길어지면 다음 주 계획에서 다시 다루도록 권고
