# 회의 전 30분 브리프
지정된 회의 1건에 대해, 다음 입력을 모아 한 장 브리프를 만드세요.

## 입력 소스
1. 구글 캘린더 MCP로 회의 일정 확인 (회의명·시간·참석자·설명)
2. `meetings/` 폴더에서 같은 시리즈의 지난 회의록 최근 3건 읽기
   - 회의 시리즈 식별: 회의명에서 일자·차수를 제외한 제목으로 매칭
3. 슬랙 MCP로 같은 회의명·주제 키워드가 들어간 최근 7일 메시지 (관련 채널 + 참석자 DM)
4. 지메일 MCP로 같은 주제의 최근 7일 스레드 (외부 참석자가 있을 때)

## 출력 양식

### 📋 {회의명} 브리프
**일시**: YYYY-MM-DD HH:MM ~ HH:MM (소요 N분)
**참석자**: (이름 목록)

#### 1. 회의 맥락
이 시리즈가 무엇을 다루는 회의인지, 최근 흐름 1~2문장.

#### 2. 지난 회의 결정 + 미해결 액션
- 결정 사항: 지난 1~3건
- 미해결 액션: 담당자 / 항목 / 기한 / 현재 상태

#### 3. 이번 안건
- 지난 회의에서 넘어온 안건 (자동 추출)
- 슬랙·이메일에서 이번 회의 안건으로 언급된 항목

#### 4. 참석자 최근 입장
- 참석자별로 최근 7일에 슬랙·이메일에서 한 발언 1~2줄

#### 5. 내가 준비할 포인트
- 본인 안건, 본인 책임 액션 진척 보고, 결정이 필요한 항목

#### 6. 예상 소요
- 안건당 분 단위 추정. 합계가 회의 시간을 넘으면 경고

## 주의사항
- 지난 회의록이 없으면 “신규 회의” 표시
- 슬랙·이메일 결과가 너무 많으면 관련도 상위 5건만 인용
- 브리프는 출력만, 파일 저장은 하지 않음
