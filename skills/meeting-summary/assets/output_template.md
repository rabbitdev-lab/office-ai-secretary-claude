# 변형 케이스

## 케이스 A: 단순 정보 공유 회의 (의사결정 없음)

```markdown
# [회의 제목]

## 메타 정보
- **일시**: YYYY-MM-DD HH:MM
- **참석자**: ...
- **회의 목적**: 진행 상황 공유

## 결정사항
- 해당 없음 (정보 공유 목적)

## 액션 아이템
- [ ] [담당자] ...

## 다음 회의 안건
- 해당 없음

## 주요 논의 내용
- 각 팀 진행 상황 요약
```

## 케이스 B: 메타 정보가 부족한 raw STT

```markdown
# 제품 로드맵 논의 (제목 추정)

## 메타 정보
- **일시**: 미상
- **참석자**: 화자1, 화자2, 화자3 (이름 식별 불가)
- **회의 목적**: 다음 분기 우선순위 결정

## 결정사항
...
```

원문에 정보가 없으면 추측하지 말고 명시적으로 `미상`/`식별 불가`로 표기합니다.
