# 문서에서 데이터 추출
문서 여러 개를 읽어 사용자가 정한 항목 스키마대로 값을 뽑아 정리하세요.

## 입력
- 대상 문서 여러 개 (PDF·마크다운·텍스트)
- 뽑을 항목 스키마 (사용자가 지정. 없으면 먼저 물음)

## 출력
- 마크다운 표 또는 CSV (사용자가 고름)
- 표 아래에 추출 실패 항목 목록

## 주의사항
- 항목 값이 명확히 추출되지 않으면 "모호함" 또는 빈 셀로 표시. 임의로 추론해서 채우지 않음
- 숫자·날짜는 가능하면 통일된 형식으로 변환 (예: 모든 날짜 YYYY-MM-DD)
- 추출 실패 항목은 표 아래에 별도로 정리. 사용자가 수동 보정 가능
- CSV 출력 시 셀 안의 콤마는 자동 이스케이프
