# 월간 계획 생성
`goals/okr.md`를 읽고, `plans` 폴더의 지난달 월간 계획에서 미완료 항목을 가져와, 이번 달 월간 계획 파일을 작성하세요.

## 입력
- OKR 파일: `goals/okr.md`
- 지난달 계획: `plans/{YYYY-MM-1}-monthly.md` (있을 때만)
- 옵션: Google Calendar 커넥터가 연결돼 있으면 이번 달 주요 일정도 반영

## 출력 양식 (`plans/{YYYY-MM}-monthly.md`)

```
# {YYYY}년 {N}월 월간 계획

## 이번 달 집중 목표 (3개 이내)
1. {목표} — 관련 KR: 1.1

## 주요 산출물·마일스톤

| 목표 | 산출물 | 마일스톤 |
|---|---|---|

## OKR 정렬 표

| KR | 이번 달 기여 항목 | 상태 |
|---|---|---|

## 지난달 이월 항목

- 항목 + 원인 + 이번 달 처리 방식
```

## 주의사항
- 집중 목표는 3개 이하로 제한. 4개 이상이면 우선순위가 흐려짐
- "관련 KR"이 비어 있는 목표는 OKR 정렬 문제 신호. 사용자에게 확인 요청
- 산출물 예상 소요는 임의로 추정하지 않음. 계획을 만들 때 사용자에게 물어 확인해 기입
- 캘린더 일정은 종일·휴가 제외, 외부 미팅·발표·마감일만 반영
