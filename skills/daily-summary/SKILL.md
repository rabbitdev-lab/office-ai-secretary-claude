# 일일 마무리
이번 주 weekly-plan과 오늘 활동(캘린더·메일·할 일)을 읽고, 완료/미완료를 정리해 저장하세요.

## 입력
- 이번 주 계획: `plans/{YYYY}-W{NN}-weekly.md`
- 오늘 활동: 캘린더(참석 회의), 지메일(보낸 메일), 할 일 목록(완료 항목) — 커넥터 연결 시
- 옵션: 사용자가 추가로 입력하는 메모

## 출력 양식 (`reviews/{YYYY-MM-DD}-daily.md`)
- 완료 항목 (활동 출처 표시) + 주간 목표 연결
- 미완료 항목 (원인 + 내일 처리 방식)
- 계획에 없던 처리 (회의에서 나온 즉석 일)
- 주간 목표 기여 한 줄 평가

## 주의사항
- 미완료 원인은 시간 부족 / 외부 의존 / 우선순위 낮춤 / 모호함 중에서 분류. 추론 안 되면 비워 둠
- 모든 미완료는 내일 할 일로 "[이월]" 표시와 함께 넘김
- 커넥터가 없으면 할 일 목록만으로 정리하고, 활동은 사용자가 보태게 함
