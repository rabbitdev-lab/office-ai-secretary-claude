# 슬랙 샘플 메시지

Chapter 04 실습 06에서 테스트용 워크스페이스에 넣는 메시지입니다. 이 메시지를 넣어 두어야 실습 07~10의 브리핑·할 일 분류·보고 취합·DM 리마인더를 돌려 볼 수 있습니다.

채널 `team-notice`, `proj-campaign`, `team-daily-report` 세 개를 먼저 만들고, 팀 동료 역할을 할 계정(여기서는 김기획)을 초대해 두세요.

대괄호 안의 이름은 어느 계정으로 보낼지를 뜻합니다. `@내이름` 자리에는 본인의 슬랙 표시 이름을 넣으세요.

## #team-notice

```
[김기획] 5월 정기 면담 일정 확정입니다. @내이름 님은 5/15(금) 14:00입니다.
[김기획] 보안 교육 이수 마감은 5/12(화)입니다. 아직 안 하신 분은 오늘 안에 완료해주세요.
```

## #proj-campaign

```
[김기획] 캠페인 메인 비주얼 시안 2종 올렸습니다. @내이름 확인 부탁드려요.
[김기획] 카피 A안·B안 사내 투표는 5/12(화) 15:00 마감입니다.
[내 계정] 광고 단가가 작년 대비 18% 올라서 예산 재검토가 필요할 것 같습니다.
```

## #team-daily-report

```
[내 계정] [완료] Q2 캠페인 일정표 초안 [진행 중] 경쟁사 조사 [이슈] 없음
[김기획] [완료] 메인 비주얼 시안 2종 [진행 중] 상세 페이지 [이슈] 폰트 라이선스 확인 필요
```
