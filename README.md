# 사무업무 AI 비서 에이전트 스킬 예제 저장소

『사무업무 AI 비서 에이전트 스킬』의 실습에서 만드는 스킬 26개와, 실습에 넣어 볼 예제 파일을 모아 둔 곳입니다. 앞 실습에서 만든 파일을 뒤 실습이 다시 읽는 경우에는 그 파일도 들어 있습니다.

- 책에서 쓰는 도구: 클로드 데스크톱 앱, 옵시디언
- 실습 환경 준비는 **Chapter 03 내 컴퓨터에서 클로드 스킬 돌려보기**에서 다룹니다.

## 내려받기

프로그램을 설치하거나 명령어를 입력할 필요가 없습니다.

1. 이 페이지 오른쪽 위의 초록색 **[Code]** 버튼을 클릭합니다.
2. **[Download ZIP]** 을 클릭하면 전체 파일이 압축 파일 하나로 내려받아집니다.
3. 내려받은 압축 파일을 풉니다.

## 어디에 복사하나요

책에서는 홈 폴더 안에 `obsidian` 폴더를 만들고, 그 안의 `claude-work` 폴더를 실습 공간으로 씁니다. 경로를 짧게 쓸 때는 `~/obsidian/claude-work`라고 적습니다.

여기 있는 폴더들은 그 안에 들어갈 폴더와 이름이 같습니다. 압축을 푼 뒤 **지금 할 실습에 필요한 파일만** 같은 이름의 폴더에 복사하세요. 파일마다 넣는 시점이 다르니 다음의 실습별 안내를 확인하세요.

| 여기 있는 것 | 어디에 복사하나 | 무엇이 들어 있나 |
| --- | --- | --- |
| `skills` 폴더 | claude-work 안의 같은 이름 폴더 | 책에서 만드는 완성 스킬 26개 |
| `data` 폴더 | 같은 이름 폴더 | 실습에 넣어 볼 예제 파일 |
| `meetings` `notes` `daily` 폴더 | 같은 이름 폴더 | 회의록·메모·데일리 노트 샘플 |
| `slack` `notion` 폴더 | 복사하지 않음 | 슬랙과 노션에 직접 붙여넣거나 올리는 자료 |
| `goals` `plans` `reviews` 폴더 | 같은 이름 폴더 | 뒤 실습이 다시 읽는 목표·계획·회고 |
| `TASKS.md` | claude-work 바로 아래 | 업무 조회·계획·마감 확인·하루 마무리에 쓰는 할 일 목록 |

책을 순서대로 따라 하며 이미 만든 파일이 있다면 그것을 이어서 쓰세요. 중간 실습부터 시작한다면 여기 있는 파일을 복사해 넣으면 됩니다.

## 스킬을 먼저 복사해도 되나요

실습을 따라 하며 직접 만들 계획이라면 **미리 복사하지 않기를 권합니다.** 여기 있는 스킬은 실습에서 만드는 것과 이름이 같습니다. 미리 넣어 두면 클로드가 스킬을 만들 때 같은 이름의 폴더가 이미 있는 상태가 되어, 내가 만든 것과 내려받은 것이 섞이거나 한쪽이 지워집니다.

- 실습은 실습대로 진행하고, 여기 있는 파일은 **정답지**로 비교해 보세요.
- 만드는 과정을 건너뛰고 바로 쓰고 싶은 스킬만 골라 복사해도 됩니다.
- 이미 복사해 둔 스킬을 실습에서 다시 만들고 싶다면, 그 폴더를 `skills` 폴더 밖으로 빼 두었다가 실습을 마친 뒤 비교하세요.

`data` 폴더의 예제 파일도 그 실습을 시작할 때 복사하세요. 엑셀 분석처럼 파일 내용이 바뀌는 실습은 내려받은 원본을 따로 보관해 두면 처음부터 다시 하기 쉽습니다.

| 파일 | 언제 넣나 |

| `notes/2026-05-02_스킬설계.md` | 실습 35에서 메모를 더해 점검할 때 넣습니다. 처음 훑을 때는 넣지 않습니다. |
| `goals/okr.md` | 실습 44에서 월간 계획을 만들기 전에 준비합니다. |
| `plans/2026-05-monthly.md` | 실습 45·46·47에서 주간 계획과 예상 시간, 마감을 확인할 때 씁니다. |
| `plans/2026-W20-weekly.md` | 실습 46·47·49에서 한 주 업무와 하루 마무리를 확인할 때 씁니다. |
| `reviews/2026-05-12-daily.md` 등 일일 요약 | 실습 49에서 주간 회고로 넘어가기 직전에 준비합니다. 한 주 전체를 정리하려면 그 주의 다른 날 기록도 있어야 합니다. |
| `reviews/2026-W20-weekly-review.md` 등 주간 회고 | 실습 50의 주간 보고와 성과 정리, 연말 회고, 다음 주 계획에 씁니다. |
| `TASKS.md` | 실습 43·44·45·47·48·49에서 씁니다. 실습마다 끝난 일과 남은 일이 다르니 그 시점 상태로 맞춰 두세요. |

`meetings` 폴더는 Chapter 06과 Chapter 11이 함께 씁니다. 지금 하는 챕터의 파일만 넣어야 다른 챕터의 회의록이 검색 결과나 집계에 섞이지 않습니다. `notes` 폴더도 처음에 넣을 메모와 점검할 때 더할 메모를 나눠서 넣으세요.

노션에 올리는 CSV는 아직 정리하지 않은 프로젝트 자료와 태스크·목표 자료입니다. 실습 중에 만드는 콘텐츠 캘린더와 현황 페이지, 회의록을 저장할 곳은 책의 안내대로 준비하세요. 이미 등록을 마친 결과를 미리 넣어 두면 클로드가 중복으로 보거나 집계 숫자가 달라집니다.

## 스킬이 목록에 보이지 않을 때

- 클로드는 새 채팅창을 시작할 때 스킬 목록을 다시 읽습니다. 복사한 뒤 채팅창을 새로 열어 주세요.
- 스킬 파일에 내 컴퓨터에 없는 경로가 들어 있을 수 있습니다. [Code] 탭에서 이렇게 요청하면 클로드가 고쳐 줍니다.

```
이 스킬 파일에 내 컴퓨터에 없는 경로가 있는지 확인하고, 내 경로에 맞게 고쳐줘.
```

- 클로드는 `.claude/skills`라는 숨은 폴더에서 스킬을 찾습니다. 이 폴더가 눈에 보이는 `skills` 폴더를 가리키도록 연결해 두는데, 그 연결은 Chapter 03에서 만듭니다. 스킬이 계속 보이지 않으면 Chapter 03의 환경 준비를 다시 확인하세요.

## 폴더 구조

| 폴더 | 무엇이 들어 있나 |
| --- | --- |
| `skills` | 완성 스킬 26개. 폴더 이름이 곧 스킬 이름입니다 |
| `data` | 실습에 넣어 볼 예제 파일. 견적서는 `quotes`, 이력서는 `resumes` 폴더에 따로 있습니다 |
| `meetings` | 회의록 샘플 |
| `notes` | 주제 메모 샘플 |
| `daily` | 데일리 노트 샘플 |
| `slack` | 슬랙 채널에 붙여넣을 메시지 |
| `notion` | 노션에 올릴 프로젝트·태스크·목표 자료 |
| `goals` | 월간 계획을 만들 때 읽는 분기 목표 |
| `plans` | 뒤 실습이 다시 읽는 월간·주간 계획 |
| `reviews` | 주간 회고와 연말 정리에 쓰는 하루·한 주 기록 |
| `TASKS.md` | 각 실습 시점의 할 일 목록 |

지식 카드나 분석 보고서, 대시보드처럼 실습으로 만들어 내는 결과물은 여기 없습니다. 직접 만들어 보는 것이 실습이기 때문입니다. `goals`·`plans`·`reviews` 폴더의 파일은 결과물이면서 동시에 뒤 실습이 다시 읽는 재료라 함께 넣었습니다.
