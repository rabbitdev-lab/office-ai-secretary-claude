# 사무업무 AI 비서 에이전트 스킬 예제 저장소

이 저장소는 『사무업무 AI 비서 에이전트 스킬』에서 만드는 스킬 26개와 원하는 결과를 얻기 위해 전달하는 입력 파일을 제공합니다. 앞 실습에서 만든 파일을 다음 실습이 입력으로 읽는 경우에는 그 파일도 포함합니다.

- 책에서 쓰는 도구: 클로드 데스크톱 앱, 옵시디언
- 실습 환경 준비는 **Chapter 03 내 컴퓨터에서 클로드 스킬 돌려보기**에서 다룹니다.

## 내려받기

프로그램을 설치하거나 명령어를 입력할 필요가 없습니다.

1. 이 페이지 오른쪽 위의 초록색 **[Code]** 버튼을 클릭합니다.
2. **[Download ZIP]** 을 클릭하면 전체 파일이 압축 파일 하나로 내려받아집니다.
3. 내려받은 압축 파일을 풉니다.

## 어디에 복사하나요

책에서는 옵시디언 보관함 `~/obsidian/claude-work`를 프로젝트 폴더로 씁니다. 이 저장소는 그 폴더와 같은 구조입니다. 압축을 푼 뒤 **진행할 실습에 필요한 파일만** 같은 경로에 복사하세요. 파일마다 사용하는 시점이 다르므로 아래의 실습별 안내를 확인하세요.

| 저장소 폴더 | 복사 위치 | 무엇이 들어 있나 |
| --- | --- | --- |
| `skills/` | `~/obsidian/claude-work/skills/` | 책에서 만드는 완성 스킬 |
| `data/` | `~/obsidian/claude-work/data/` | 실습에 쓰는 예제 파일 |
| `meetings/` `notes/` `daily/` | 같은 이름 폴더 | 회의록·메모·데일리 노트 샘플 |
| `slack/` `notion/` | 복사하지 않음 | 슬랙·노션에 직접 붙여넣거나 가져오기로 올리는 자료 |
| `goals/` `plans/` `reviews/` | 같은 이름 폴더 | 다음 실습에 입력으로 전달하는 목표·계획·회고 |
| `TASKS.md` | `~/obsidian/claude-work/TASKS.md` | 업무 조회·계획·마감 확인·일일 마무리에 쓰는 할 일 목록 |

책을 순서대로 따라 하며 이미 만든 입력 파일이 있다면 그 파일을 이어서 사용하세요. 중간 실습부터 시작할 때는 저장소의 해당 입력 파일을 복사해 사용할 수 있습니다.

## 스킬을 먼저 복사해도 되나요

실습을 따라 하며 직접 만들 계획이라면 **미리 복사하지 않기를 권합니다.** 저장소의 스킬은 실습에서 만드는 것과 이름이 같아서, 같은 이름의 폴더가 이미 있는 상태로 스킬이 만들어집니다. 그러면 내가 만든 스킬과 내려받은 스킬이 섞이거나 한쪽이 덮어써질 수 있습니다.

- 실습은 실습대로 진행하고, 이 저장소의 파일은 **정답지**로 비교해 보세요.
- 만드는 과정을 건너뛰고 바로 쓰고 싶은 스킬만 골라 복사해도 됩니다.
- 이미 복사한 스킬을 실습에서 다시 만들고 싶다면, 그 폴더를 `skills/` 밖으로 옮겨 두었다가 실습을 마친 뒤 비교하세요.

`data/`의 입력 파일도 해당 실습을 시작할 때 복사하세요. 엑셀 분석처럼 입력 파일의 내용이 바뀌는 실습은 내려받은 원본을 별도로 보관하면 다시 시작하기 쉽습니다.

## 입력 파일은 언제 넣나요

| 입력 파일 | 사용하는 시점 |
| --- | --- |
| `meetings/2026-05-17-베타-V1-정렬-회의.md` | 실습 17에서 만든 회의록을 실습 18의 분배 입력으로 사용합니다. 실습 18부터 시작할 때만 이 파일을 복사합니다. |
| `notes/2026-05-02_스킬설계.md` | 실습 35의 새 메모 추가·점검 단계에서 넣습니다. 처음 스캔할 때는 넣지 않습니다. |
| `goals/okr.md` | 실습 44에서 월간 계획을 만들기 전에 준비합니다. |
| `plans/2026-05-monthly.md` | 실습 45·46·47에서 주간 계획·예상 시간·마감을 확인할 때 사용합니다. |
| `plans/2026-W20-weekly.md` | 실습 46·47·49에서 주간 업무와 하루 마무리를 확인할 때 사용합니다. |
| `reviews/2026-05-12-daily.md` 등 일일 요약 | 실습 49의 주간 회고 단계 직전에 준비합니다. 한 주 전체를 요약하려면 해당 주의 다른 날 기록도 필요합니다. |
| `reviews/2026-W20-weekly-review.md` 등 주간 회고 | 실습 50의 주간 보고·성과 추출·연말 회고와 다음 주 계획에 사용합니다. |
| `TASKS.md` | 실습 43·44·45·47·48·49에서 사용합니다. 각 실습 시점의 미완료·완료 상태에 맞춰 준비합니다. |

`meetings/`는 Chapter 06과 Chapter 11에서 함께 쓰는 폴더입니다. 해당 챕터의 입력만 넣어 다른 실습의 회의록이 검색·집계에 섞이지 않게 하세요. `notes/`도 초기 메모와 점검 단계에서 추가할 메모를 구분해 넣습니다.

노션에 가져오는 CSV는 정리 전 프로젝트 데이터와 태스크·목표 데이터입니다. 실습 중 만드는 콘텐츠 캘린더·현황·회의록 저장 대상은 책의 안내에 따라 준비하세요. 등록이 끝난 결과 데이터를 미리 넣으면 중복 판정이나 집계 결과가 달라질 수 있습니다.

## 스킬이 목록에 보이지 않을 때

- 클로드는 새 채팅창을 시작할 때 스킬 목록을 다시 읽습니다. 복사한 뒤 채팅창을 새로 열어 주세요.
- 스킬 파일에 내 컴퓨터에 없는 경로가 들어 있을 수 있습니다. [Code] 탭에서 이렇게 요청하면 클로드가 고쳐 줍니다.

```
이 스킬 파일에 내 컴퓨터에 없는 경로가 있는지 확인하고, 내 경로에 맞게 고쳐줘.
```

- `.claude/skills`는 `skills` 폴더를 가리키는 연결(심볼릭 링크)입니다. 연결이 없으면 Chapter 03의 환경 설정 안내에 따라 준비하세요.

## 폴더 구조

```
skills/        완성 스킬 26개 (폴더 이름이 곧 스킬 이름)
data/          실습 입력 파일 (quotes/, resumes/ 포함)
meetings/      회의록 샘플
notes/         주제 메모 샘플
daily/         데일리 노트 샘플
slack/         슬랙 채널에 붙여넣을 메시지 원문
notion/        프로젝트·태스크·목표 DB 입력 CSV
goals/         월간 계획에 전달하는 분기 목표
plans/         다음 실습에 전달하는 월간·주간 계획
reviews/       주간·연말 회고 등에 전달하는 일일·주간 기록
TASKS.md       각 실습 시점의 할 일 목록
```

지식 카드, 분석 보고서, 대시보드처럼 완성 결과를 확인하기 위한 파일은 실습을 진행하며 만듭니다. `goals/`, `plans/`, `reviews/`의 파일은 뒤 실습에서 다시 읽는 입력이므로 위 구조에 포함되어 있습니다.
